# 我上早八 / 8 AM Class

当前测试版本：**0.2.1**，适用于 Forerunner 255。修复0.2.0整夜运行后重开时，在日志恢复函数中触发watchdog的真机问题；恢复已清洗日志时直接复用有界字符串，保留原有固定闹钟和日志。手表应用内可切换中文和英文。首页用 UP/DOWN 滚动选择「启动固定闹钟」「修改闹钟」「运行记录」「说明书」「设置」，按 START 进入，按 BACK 返回。

## 设置闹钟

进入「修改闹钟」时，时间从**手表当前时刻**开始显示，不再固定为 07:00。先调小时，再按 START 调分钟；UP/DOWN 单击增减 1，长按连续调整并加速。分钟调好后按 START 保存并启动。下次打开应用，直接选择首页的「启动 HH:MM」即可，保存的时刻不会丢失。若设定时刻已经过去，闹钟安排在第二天的同一时刻。

「每日重复」默认开启。停止一次响铃或响铃十分钟超时后，应用会继续等待第二天的同一时刻；提前智能唤醒后也不会再次在当天截止时刻提醒。BACK 取消当前监测及连续运行，但保留固定时刻。此功能要求应用保持前台打开；退出应用、重启手表后，需要再次从首页启动，不能代替系统后台闹钟。

监测页同时显示**设置好的截止闹钟时刻**和**剩余倒计时**。在截止时间前 30 分钟，应用尝试结合加速度计活动量与可用的光学心率读数，寻找合适的提前唤醒时机；否则在截止时间触发提醒。按 BACK 取消监测，响铃时按 START 停止。

首页的「说明书」有四页。UP/DOWN 翻页，BACK 返回。首页「设置」提供：

- 语言：中文 / English。
- 声音：关闭 / 闹铃 / 响亮 / 渐进。渐进采用自编蜂鸣序列：前30秒单短音，每10秒一次；30–60秒增加音符，每5秒一次；60秒后加长为三音，每2秒一次。新安装默认渐进，升级会保留原有选择。接口没有扬声器音量参数，不能实现物理音量淡入，也不能在普通 FR255 watch-app 中播放 MP3/WAV。
- 振动：关闭 / 柔和 / 强烈 / 渐进。渐进为300毫秒→1000毫秒→2000毫秒，重复间隔10秒→5秒→2秒，阶段同上。FR255 马达 duty cycle 固定，改变的是时长和密度，不能改变物理强度。程序不允许声音和振动同时关闭。
- 每日重复：开 / 关。
- 导入作息起床时刻：读取 Garmin 用户资料中的计划起床时刻，保存为固定闹钟；不把计划作息当成真实睡眠数据。需要 UserProfile 权限。

这些设置保存在手表应用中。**睡前请关闭勿扰模式**，并检查睡眠模式不会自动重新打开勿扰。真机对照测试确认：之前的无声、无振动是勿扰模式开启所致。应用显示「勿扰已开」时，Connect IQ 的声音和振动提示可能被静音。

本轮重新核对后，FR255 公开 Connect IQ API 仍不能读取原生实时睡眠分期或实际睡眠时长。用户测试发现原生记录可正常生成，这说明两者可以共存，但不代表应用获得读取权限。旧 isSleepMode 标记仅作诊断，可能为空且不用于决定唤醒。详情与官方来源见 [睡眠接口核查](docs/sleep-api-findings.md)。在验证可靠性期间，请另设一个相同时间的手表原生闹钟。

## 运行日志

应用默认记录启动、固定时间、计划作息、传感器开始/异常、候选信号、触发原因（截止时间/连续动作/动作及心率）、提醒阶段、声音/振动异常、停止原因。每10分钟保存一次心率、电量和采样摘要；勿扰/音振开关及旧睡眠模式标记每分钟检查并在变化时记一条。最近128条事件与本轮/上轮摘要存入手表，首页「运行记录」可查看，START 切换摘要/详情，UP/DOWN 切换事件。

日志中的 armedElapsedSeconds 是监测运行时长，quietSampledSeconds 是被采样的安静秒数，legacySleepModeTrueSeconds 是有效采样间隔内旧模式标记为真的累计秒数；**都不是实际睡眠时长**。原生睡眠时长标为不可用/null。真实夜间结果可在后续与 Garmin Connect 原生记录对照。

若要用 USB 读取文本日志，安装时还需在 GARMIN/APPS/LOGS 创建与实际 PRG 同名的 TXT。详见 [日志安装及反馈说明](docs/runtime-logs.md)。日志保存在本机，不自动联网；`device-logs/` 已被 Git 忽略。

## 编译和安装

1. `dist/8am-class.prg` 是使用 Connect IQ SDK 9.3.0 为 Forerunner 255 编译的版本。将它复制到手表的 `GARMIN/APPS` 目录。详见 [Garmin 的侧载教程](https://developer.garmin.com/connect-iq/connect-iq-basics/your-first-app/)。Connect IQ 开发者后台上传时使用 `dist/8am-class.iq`。
2. 如需自行构建，在 [Connect IQ SDK Manager](https://developer.garmin.com/connect-iq/sdk/) 中安装 SDK 和 Forerunner 255 设备定义，并准备 RSA 4096 位开发者签名密钥。密钥应存放在项目目录之外，不要提交到仓库。
3. 在 VS Code 中打开此目录，把 **Monkey C: Developer Key Path** 指向自己的密钥，选择 Forerunner 255 后执行 **Monkey C: Build for Device**。也可使用 `monkeyc -f monkey.jungle -d fr255 -y <密钥路径> -o build/8am-class.prg`。

中文界面采用应用自带的精简点阵字体，因为英文系统语言下的 FR255 模拟器无法用内置字体显示汉字。字形由 Noto Sans SC 生成；相关版权和 SIL OFL 1.1 许可见 `fonts/OFL.txt`。若修改中文文案，在 Windows 上运行 `tools/generate-chinese-font.ps1` 更新字形图集，再重新编译。

0.2.1 已通过 FR255 编译及10项模拟器回归/集成测试：跨午夜、当前同分钟、提前唤醒后的每日重复、渐进阶段边界、固定时刻Storage保存/恢复、截止触发、上轮原因保留，以及128条×180字符的满载日志恢复/滚动/重开。真机0.2.0的错误报告明确指向RunLog.clean的watchdog；原来的普通模拟器测试没有复现该设备执行时限问题。2026-11-13已在保留原有日志和设置的同一真机上更新0.2.1，用户确认退出后重开两次均正常进入主页。
